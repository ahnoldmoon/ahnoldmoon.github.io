개인정보처리방침

최종 수정일: 2026년 8월 13일

한 줄 요약 — LinkGuard는 어떠한 개인정보도 수집·저장·전송하지 않습니다. 모든 분석은 사용자의 브라우저 안에서 이루어집니다.

1. 수집하지 않는 정보

  • 방문한 웹사이트 주소 및 방문 기록
  • 페이지 내용, 입력값, 쿠키, 로그인 정보
  • 이메일 주소, 이름 등 개인 식별 정보
  • 사용 통계, 분석(analytics), 광고 식별자

개발자는 사용자의 브라우징 활동을 볼 수 없으며, 이를 수집하는 서버 자체가 존재하지 않습니다.

2. 확장 프로그램이 하는 일

링크에 마우스를 올리면 그 링크의 주소 문자열만을 브라우저 안에서 검사합니다 (도메인 구조, 유사 브랜드 여부, 파일 확장자 등). 이 과정에서 외부와의 통신은 없습니다.

3. 선택 기능을 켰을 때의 외부 통신

사용자가 설정에서 "네트워크 조회"를 직접 켠 경우에만 다음 통신이 발생합니다.

기능통신 대상보내는 것
도메인 등록일 조회rdap.org 및 해당 도메인 등록기관의 RDAP 서버조회할 도메인 이름
리다이렉트 경로 추적사용자가 확인을 요청한 그 링크의 서버HTTP 요청 (쿠키·인증정보 미포함)
  • 두 기능 모두 기본값은 꺼짐이며, 꺼진 상태에서는 어떤 외부 통신도 하지 않습니다.
  • 리다이렉트 추적은 사용자가 버튼을 누른 링크에 대해서만 실행됩니다.
  • 요청에 쿠키·인증정보를 포함하지 않습니다(credentials: omit).
  • 조회 결과는 사용자의 브라우저에만 저장됩니다(도메인 등록 정보 7일, 추적 결과 6시간). 설정에서 언제든 삭제할 수 있습니다.
  • 개발자는 이 통신 내용을 수신하거나 보관하지 않습니다.

4. 브라우저에 저장되는 정보

chrome.storage에 다음이 저장되며, 모두 사용자 기기에만 남습니다.

  • 사용자 설정(표시 지연시간, 표시 기준, 신뢰 도메인 목록, 제외 사이트 목록 등)
  • 조회 결과 캐시(도메인 등록일, 리다이렉트 경로)

크롬 동기화를 사용하는 경우 설정 값은 사용자 본인의 구글 계정을 통해 기기 간 동기화될 수 있습니다. 이는 크롬의 기능이며 개발자에게 전달되지 않습니다. 확장 프로그램을 삭제하면 저장된 정보도 함께 삭제됩니다.

5. 제3자 제공

없습니다. 어떠한 정보도 판매·공유·양도하지 않습니다.

6. 원격 코드

원격 코드를 내려받아 실행하지 않습니다. 모든 코드는 확장 프로그램 패키지에 포함되어 있습니다.

7. 아동 대상 여부

만 14세 미만 아동을 대상으로 하지 않으며, 연령 정보를 수집하지 않습니다.

8. 방침 변경

변경 시 이 문서의 최종 수정일을 갱신하고, 중요한 변경 사항은 확장 프로그램 업데이트 설명에 안내합니다.
