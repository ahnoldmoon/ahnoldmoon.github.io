Chrome 확장 프로그램

Table to Excel(표를 엑셀로 저장)
개인정보처리방침

시행일: 2026년 8월 9일 · 최종 수정일: 2026년 8월 9일
한 줄 요약 이 확장 프로그램은 사용자의 개인정보를 수집하지 않습니다.
  • 웹페이지에서 읽은 표 데이터는 사용자의 브라우저 안에서만 처리되며 어떤 서버로도 전송되지 않습니다.
  • 사용 횟수와 라이선스 키는 사용자 기기(chrome.storage.local)에만 저장됩니다.
  • 외부 통신은 유료 라이선스 키의 유효성 확인 1건뿐입니다.

1. 처리하는 데이터

1-1. 웹페이지의 표 데이터

사용자가 툴바 아이콘을 클릭한 그 순간, 현재 활성 탭의 <table> 요소에 담긴 텍스트를 읽어 엑셀(.xlsx) 파일로 변환합니다. 이 데이터는 브라우저 메모리에서만 처리되어 사용자의 컴퓨터에 파일로 저장되며, 개발자를 포함한 누구에게도 전송되지 않고 저장·보관되지도 않습니다. 팝업 창을 닫으면 메모리에서 사라집니다.

1-2. 사용자 기기에만 저장되는 정보

저장 항목 내용과 목적
usage 이번 달 저장 횟수(예: { month: "2026-08", count: 3 })와 해당 월 정보. 무료 사용 한도(월 20회)를 계산하기 위해 사용합니다. 개인을 식별할 수 있는 정보는 포함하지 않습니다.
license 사용자가 직접 입력한 라이선스 키, 기기 식별용 활성화 ID, 마지막 확인 시각. 유료 사용 여부를 판단하기 위해 사용합니다.

두 항목 모두 Chrome의 chrome.storage.local(사용자 기기 내부 저장소)에만 저장되며 외부로 동기화되거나 전송되지 않습니다. 확장 프로그램을 삭제하면 함께 삭제됩니다.

2. 수집하지 않는 정보

이름, 이메일, 전화번호 등 개인 식별 정보수집하지 않음
방문한 웹사이트 주소·방문 기록수집하지 않음
표 내용 등 사용자 활동 데이터수집하지 않음
위치 정보, 기기 식별자, 광고 식별자수집하지 않음
인증 정보(비밀번호, 쿠키, 토큰 등)수집하지 않음
분석·통계 도구, 광고 추적 코드사용하지 않음

3. 외부로 나가는 유일한 통신 — 라이선스 확인

유료 라이선스를 구매한 사용자가 키를 입력하면, 그 키가 유효한지 확인하기 위해 결제 처리사인 Lemon Squeezy의 공개 API(https://api.lemonsqueezy.com/v1/licenses)로 라이선스 키와 활성화 ID만 전송됩니다. 이때 표 데이터나 방문 기록 등 다른 정보는 일절 포함되지 않습니다.

  • 발생 시점: ① 사용자가 라이선스 키를 처음 등록할 때 ② 등록 후 3일에 한 번 유효성 재확인 시
  • 전송 내용: 라이선스 키, 활성화 ID(Lemon Squeezy가 발급한 값)
  • 목적: 유효한 구매인지 확인 (환불·취소된 키 차단)
  • 무료 사용자: 라이선스 키를 등록하지 않으면 이 통신은 한 번도 발생하지 않습니다.

Lemon Squeezy의 개인정보 처리에 대해서는 Lemon Squeezy 개인정보처리방침을 참고하시기 바랍니다. 결제 시 입력하는 이메일·결제 정보는 Lemon Squeezy가 직접 처리하며, 개발자는 이를 저장하지 않습니다.

4. 권한을 요청하는 이유

권한사용 목적
activeTab 사용자가 툴바 아이콘을 클릭한 바로 그 탭에 한해 접근합니다. 클릭하지 않은 탭이나 백그라운드 페이지는 읽지 않습니다.
scripting 해당 페이지에서 <table> 요소의 텍스트를 읽어오는 함수를 실행하기 위해 필요합니다.
storage 무료 사용 횟수와 라이선스 키를 사용자 기기에만 저장하기 위해 필요합니다.
api.lemonsqueezy.com 유료 라이선스 키의 유효성 확인을 위한 결제 처리사 통신에만 사용합니다.

5. 데이터의 판매·양도

개발자는 사용자 데이터를 수집하지 않으므로 제3자에게 판매·양도·공유할 데이터 자체가 없습니다. 또한 확장 프로그램의 핵심 기능과 무관한 목적(광고, 신용평가, 데이터 브로커 등)으로 데이터를 사용하지 않습니다.

6. 아동의 개인정보

이 확장 프로그램은 어떤 사용자로부터도 개인정보를 수집하지 않으므로, 만 14세 미만 아동의 개인정보 역시 수집하지 않습니다.

7. 데이터 삭제 방법

chrome://extensions에서 이 확장 프로그램을 삭제하면 기기에 저장된 사용 횟수와 라이선스 키가 함께 삭제됩니다. 라이선스 키만 해제하고 싶은 경우 아래 이메일로 문의해 주세요.

8. 방침의 변경

본 방침이 변경되는 경우 이 페이지의 내용을 갱신하고 상단의 최종 수정일을 함께 변경합니다. 중요한 변경(예: 새로운 데이터 수집)이 발생하면 확장 프로그램 업데이트 시 별도로 안내합니다.
