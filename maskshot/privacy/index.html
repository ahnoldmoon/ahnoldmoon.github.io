Chrome 확장 프로그램

MaskShot(스크린샷 개인정보 자동 마스킹)
개인정보처리방침

시행일: 2026년 8월 9일 · 최종 수정일: 2026년 8월 9일
한 줄 요약 이 확장 프로그램은 사용자의 개인정보를 수집하지 않습니다.
  • 캡처한 이미지와 그 안에서 찾아낸 내용은 사용자의 브라우저 안에서만 처리되며 어떤 서버로도 전송되지 않습니다.
  • 이미지 파일의 글자 인식(OCR)도 사용자의 컴퓨터 안에서 실행되며 인터넷 통신이 발생하지 않습니다.
  • 사용 횟수, 라이선스 키, 설정은 사용자 기기(chrome.storage.local)에만 저장됩니다.
  • 외부 통신은 유료 라이선스 키의 유효성 확인 1건뿐입니다.

1. 처리하는 데이터

1-1. 페이지 캡처 모드에서 읽는 내용

사용자가 툴바 아이콘을 클릭한 그 순간, 현재 활성 탭에서 화면에 보이는 글자를 읽어 개인정보에 해당하는 패턴을 찾고, 그 글자가 화면의 어느 위치에 있는지 좌표를 계산합니다. 그런 다음 화면에 보이는 영역을 캡처해 계산된 위치를 가립니다. 이 처리는 모두 사용자의 브라우저 안에서 이루어지며, 개발자를 포함한 누구에게도 전송되지 않고 저장·보관되지도 않습니다.

1-2. 이미지 파일 모드와 글자 인식(OCR)

사용자가 편집 화면에 이미지를 끌어다 놓거나 Ctrl+V로 붙여넣으면, 이미지 안의 글자를 읽어 개인정보 패턴을 찾습니다. 글자 인식에는 Tesseract.js를 사용하며, 이 엔진과 인식에 필요한 데이터는 확장 프로그램 안에 함께 포함되어 있습니다. 따라서 인식 과정에서 이미지가 외부로 전송되지 않으며 인터넷 통신도 발생하지 않습니다.

1-3. 캡처한 이미지의 취급

캡처한 이미지는 디스크에 기록되지 않는 메모리 영역 (chrome.storage.session과 서비스 워커 메모리)에 잠깐 머무르며, 편집 화면이 읽어가는 즉시 삭제됩니다. 이미지가 사용자의 컴퓨터에 파일로 저장되는 것은 사용자가 저장 버튼을 눌렀을 때뿐이며, 이 경우 사용자의 다운로드 폴더에 저장됩니다.

1-4. 사용자 기기에만 저장되는 정보

저장 항목 내용과 목적
usage 이번 달 저장·복사 횟수(예: { month: "2026-08", count: 3 })와 해당 월 정보. 월 무료 한도를 계산하기 위해 사용합니다. 개인을 식별할 수 있는 정보는 포함하지 않습니다.
license 사용자가 직접 입력한 라이선스 키, 기기 식별용 활성화 ID, 마지막 확인 시각. 유료 사용 여부를 판단하기 위해 사용합니다.
ocrTrial 이미지 파일 모드의 글자 인식(OCR) 무료 체험 사용 횟수(숫자). 남은 체험 횟수를 계산하기 위해 사용합니다.
settings 가릴 항목의 체크 상태, 사용자가 직접 입력한 지정 단어, 가리는 방식(검은 박스·모자이크·블러) 선택값. 다음 사용 시 같은 설정을 유지하기 위해 사용합니다.

위 항목은 모두 Chrome의 chrome.storage.local(사용자 기기 내부 저장소)에만 저장되며 외부로 동기화되거나 전송되지 않습니다. 확장 프로그램을 삭제하면 함께 삭제됩니다.

캡처한 이미지와 그 내용수집하지 않음

분석·통계 도구, 광고 추적 코드사용하지 않음

3. 외부로 나가는 유일한 통신 — 라이선스 확인

유료 라이선스를 구매한 사용자가 키를 입력하면, 그 키가 유효한지 확인하기 위해 결제 처리사인 Lemon Squeezy의 공개 API(https://api.lemonsqueezy.com/v1/licenses)로 라이선스 키와 활성화 ID만 전송됩니다. 이때 캡처한 이미지, 인식한 글자, 방문 기록 등 다른 정보는 일절 포함되지 않습니다.

  • 발생 시점: ① 사용자가 라이선스 키를 처음 등록할 때 ② 등록 후 주기적인 유효성 재확인 시
  • 전송 내용: 라이선스 키, 활성화 ID(Lemon Squeezy가 발급한 값)
  • 목적: 유효한 구매인지 확인 (환불·취소된 키 차단)
  • 무료 사용자: 라이선스 키를 등록하지 않으면 이 통신은 한 번도 발생하지 않습니다.

Lemon Squeezy의 개인정보 처리에 대해서는 Lemon Squeezy 개인정보처리방침을 참고하시기 바랍니다. 결제 시 입력하는 이메일·결제 정보는 Lemon Squeezy가 직접 처리하며, 개발자는 이를 저장하지 않습니다.

4. 권한을 요청하는 이유

권한사용 목적
activeTab 사용자가 아이콘을 클릭한 바로 그 탭에서만, 화면에 보이는 글자를 읽고 화면을 캡처하기 위해 필요합니다. 클릭하지 않은 탭이나 백그라운드 페이지는 읽지 않습니다.
scripting 그 페이지에서 글자와 좌표를 계산하는 함수를 실행하기 위해 필요합니다. 확장 프로그램에 포함된 코드만 실행하며, 원격 코드를 내려받아 실행하지 않습니다.
storage 무료 사용 횟수, 라이선스 키, 사용자 설정을 사용자 기기에만 저장하기 위해 필요합니다.
clipboardWrite 완성된 이미지를 클립보드로 복사하기 위해 필요합니다.
호스트 api.lemonsqueezy.com 유료 라이선스 키의 유효성 확인 전용입니다. 라이선스 키와 활성화 ID 외 어떤 데이터도 보내지 않으며, 키를 등록하지 않은 사용자에게는 이 통신이 한 번도 발생하지 않습니다.

5. 데이터의 판매·양도

개발자는 사용자 데이터를 수집하지 않으므로 제3자에게 판매·양도·공유할 데이터 자체가 없습니다. 또한 확장 프로그램의 핵심 기능과 무관한 목적(광고, 신용평가, 데이터 브로커 등)으로 데이터를 사용하지 않습니다.

6. 아동의 개인정보

이 확장 프로그램은 어떤 사용자로부터도 개인정보를 수집하지 않으므로, 만 14세 미만 아동의 개인정보 역시 수집하지 않습니다.

7. 데이터 삭제 방법

chrome://extensions에서 이 확장 프로그램을 삭제하면 기기에 저장된 사용 횟수, 라이선스 키, OCR 체험 횟수, 설정이 함께 삭제됩니다. 라이선스 키만 해제하고 싶은 경우 아래 이메일로 문의해 주세요.

8. 방침의 변경

본 방침이 변경되는 경우 이 페이지의 내용을 갱신하고 상단의 최종 수정일을 함께 변경합니다. 중요한 변경(예: 새로운 데이터 수집)이 발생하면 확장 프로그램 업데이트 시 별도로 안내합니다.

English summary: This extension does not collect any personal data. Screenshots and the text detected inside them are processed entirely within your browser and are never transmitted anywhere. Text recognition (OCR) for dropped or pasted images runs locally via a bundled copy of Tesseract.js, with no network access. Captured images stay only in non-disk memory (chrome.storage.session and the service worker) and are deleted as soon as the editor reads them; a file is written to your Downloads folder only when you click save. Usage counts, your license key, OCR trial count, and settings are stored only on your device via chrome.storage.local. The only outbound request is a license-key validation call to Lemon Squeezy, sending nothing but the license key and activation ID, and it never occurs unless you enter a paid license key.
