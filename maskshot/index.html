자동 마스킹 (MaskShot)

캡처 이미지에서 개인정보 패턴을 자동으로 찾아 가려 주는 Chrome 확장 프로그램입니다.

Chrome 웹 스토어에서 설치하기 무료로 시작할 수 있습니다. 저장·복사 월 20회까지 무료입니다.

이미지와 찾아낸 내용은 브라우저 안에서만 처리되며 어떤 서버로도 전송되지 않습니다. 가리기 위해 이미지를 외부 사이트에 올릴 필요가 없습니다.

이런 일을 대신합니다

업무 화면을 캡처해 공유하려면 주민등록번호, 카드번호, 계좌번호, 전화번호 같은 항목을 그림판이나 이미지 편집 도구로 하나씩 찾아 지워야 합니다. 놓치기 쉽고 시간도 걸립니다. 이 확장 프로그램은 캡처한 화면에서 개인정보로 보이는 부분을 자동으로 찾아 그 자리에 가림 처리를 해 줍니다.

두 가지 사용 방법

① 페이지 캡처 모드

  1. 가리고 싶은 내용이 있는 웹페이지를 엽니다.
  2. 툴바의 확장 프로그램 아이콘을 클릭합니다.
  3. 현재 탭에서 화면에 보이는 글자를 읽어 개인정보를 찾고, 그 글자가 화면의 어느 위치에 있는지 좌표를 계산한 뒤 보이는 영역을 캡처해 그 자리를 가립니다.

이미지를 다시 분석하는 것이 아니라 페이지의 텍스트를 직접 읽어 위치를 계산하는 방식이라 가림 위치가 정확합니다.

② 이미지 파일 모드

  1. 편집 화면에 이미지를 끌어다 놓거나 Ctrl+V로 붙여넣습니다.
  2. 내 컴퓨터 안에서 도는 글자 인식(OCR)이 이미지 안의 글자를 읽어 개인정보를 찾습니다.

글자 인식에는 Tesseract.js를 사용하며, 이 엔진은 확장 프로그램 안에 함께 들어 있습니다. 이미지를 어딘가로 올려 분석하는 방식이 아니므로 인터넷 통신이 발생하지 않습니다.

가리는 방식

  • 검은 박스 (기본값)
  • 모자이크
  • 블러

외부에 공개할 이미지라면 검은 박스를 권장합니다. 모자이크와 블러는 원래 픽셀 정보가 일부 남기 때문에, 이론적으로 복원을 시도하는 것이 가능합니다.

편집 화면에서 할 수 있는 일

  • 자동으로 찾지 못한 부분은 마우스로 직접 드래그해 추가로 가리기
  • 가릴 항목을 항목별로 켜고 끄기
  • Ctrl+Z로 되돌리기
  • PNG로 저장하거나 클립보드로 복사

라이선스 키 등록 방법

결제가 끝나면 입력하신 이메일로 라이선스 키가 자동으로 발송됩니다. 메일이 보이지 않으면 스팸함도 확인해 주세요.

  1. 메일에 있는 라이선스 키를 복사합니다. (XXXXXXXX-XXXXXXXX-… 형태입니다)
  2. 크롬 툴바의 MaskShot 아이콘을 클릭합니다.
  3. 맨 아래 라이선스 키 등록 / 구매를 펼칩니다.
  4. 입력칸에 키를 붙여넣고 등록을 누릅니다.
  5. 상단 배지가 ✓ Pro — 무제한으로 바뀌면 완료입니다.

무료 사용량이 남아 있어도 언제든 등록할 수 있습니다. 한도를 다 써야만 입력칸이 열리는 방식이 아니므로, 두 번째·세 번째 PC에도 설치하자마자 바로 키를 넣으시면 됩니다.

같은 키로 PC 3대까지 등록할 수 있습니다. 기기를 교체해 등록 가능 대수를 넘겼다면 메일로 문의해 주시면 초기화해 드립니다.

알아두실 점

  • 자동 탐지는 100%를 보장하지 않습니다. 저장하거나 공유하기 전에 결과를 눈으로 한 번 확인해 주세요. 놓친 부분은 직접 드래그해 가릴 수 있습니다.
  • 페이지 캡처 모드는 현재 화면에 보이는 영역만 캡처합니다. 스크롤을 포함한 전체 페이지 캡처는 다음 버전에서 제공할 예정입니다.
  • 다른 출처의 iframe 안에 있는 내용은 페이지 캡처 모드에서 좌표를 잡지 못합니다. 이 경우 캡처된 이미지에서 직접 드래그해 가려 주세요.
  • 이미지 파일 모드의 OCR은 이미지 화질과 글꼴에 따라 글자를 놓칠 수 있습니다.
  • 비밀번호 입력칸은 화면에 점으로만 보이므로 탐지 대상에서 제외됩니다.
